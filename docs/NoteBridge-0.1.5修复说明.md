# NoteBridge 0.1.5 修复说明

- 给缺少编号的笔记添加标识时，使用 Obsidian `Vault.process` 在本机原子读取和修改，并在写入时再次检查 `notebridge_id`。已经存在时不会新增；若该标识的发布记录尚未同步，则等待同步，不会擅自认领。重复的 YAML 字段仍会报错停止。
- 两台设备离线同时首次处理同一篇文章，或者外部同步工具把不同版本合并到一份笔记时，本机原子操作无法跨设备加锁。请先等待两台设备同步再操作；发现两个编号时不要随便删除，应核对已发布记录。
- 支持经核对的编号修复记录，以合并不同设备上的旧标识和未发布首次预览日期。旧设备不识别这一记录；请先在所有设备升级到 0.1.5，等待笔记和 `NoteBridge同步记录` 同步完成后再发布。
- 封面及分类支持保存后返回操作中心，也可不保存返回；状态和预览支持返回，排序页可返回发布预览。未确认的排序变更不会自动提交。
- 调整首页排序时，自动将仓库中未列入的文章加入编辑列表。网站自身的排序规则还需单独修复，本版本不会静默改动网站脚本。

安装时替换每台设备的 `main.js`、`manifest.json`、`styles.css`，保留插件设置和同步记录。自动化测试不能替代 iPhone、坚果云和真实仓库的并发验证。
